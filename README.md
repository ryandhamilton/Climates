# Climates

Climates is an advisory practice and communications agency working to make climate change a more accessible and engaging topic for general audiences.

## The website

A static, dependency-free site: `index.html` + `styles.css`. No build step, no framework. Open `index.html` in a browser to preview it locally.

### Deploying

Works out of the box with GitHub Pages: in the repo settings, enable Pages and point it at the branch root. Any static host (Netlify, Vercel, Cloudflare Pages) works the same way.

### Before launch

- Confirm the Substack URL in the newsletter section of `index.html` (currently set to `climates.substack.com`).
- Swap the contact email if a branded address replaces the Gmail one.
